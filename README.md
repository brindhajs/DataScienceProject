Travel App Customer & Booking Data Analysis

Project Overview

This project focuses on exploratory data analysis of a travel app dataset containing 100,000 customer and booking records.

The analysis looks at customer behavior, booking patterns, travel preferences, destinations, package types, ratings, cancellations, and booking amounts.

Objectives

- Analyze customer demographics and booking behavior
- Identify popular travel destinations
- Compare different travel types
- Analyze package preferences and booking amounts
- Study booking status and cancellation patterns
- Clean and prepare the dataset for analysis
- Find useful insights from the data

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

Analysis Performed

Data Cleaning

The dataset was checked for missing values and duplicate records. Invalid age and rating values were handled, and city and destination values were standardized. A cleaned dataset was also created.

Customer Analysis

The analysis covers customer age, booking amount, trip duration, customer ratings, booking count, and cancellation count.

Destination Analysis

Different destinations were compared based on the number of bookings, average booking amount, and average customer rating.

Travel and Package Analysis

Different travel types such as Business, Couple, Solo, Family, and Friends were compared.

The analysis also covers Budget, Standard, Premium, and Luxury packages.

Booking Analysis

Booking status was analyzed using Completed, Cancelled, and Pending bookings. Booking amounts, booking frequency, and cancellation patterns were also examined.

Key Findings

- The dataset contains 100,000 travel app records.
- Kashmir has the highest number of bookings in the dataset.
- Hyderabad has the highest average booking amount among the destinations.
- Goa has the highest average customer rating.
- Standard is the most commonly selected package type.
- Luxury packages have the highest average booking amount.
- Completed bookings make up the majority of the records.

Conclusion

This project helped analyze customer and booking data to understand travel preferences, destination popularity, package demand, booking trends, and cancellation behavior using Python and data analysis techniques.
